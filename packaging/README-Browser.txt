Chembrain — local browser preview

This download also includes the independent Chembrain-Paper-Workbench.html.
Use that file for private paper/source checking, structure encoding and recorded
reaction/solution preparation. Export checked facts, then use Import package
here. Review/apply missing structures, solution facts and recorded reaction
stages/conditions/evidence after checking the preview. Existing known facts and
edits are retained; conflicts require reconciliation before import. See
README-Paper-Workbench.

Double-click Chembrain.html to open the English molecular library in a modern
browser. No Python, Node.js, local server, API key or installation is required.
The app and starter chemistry data are included in this one HTML file.
DOI links open the publisher's website when you choose a reference and have
internet access. The app itself needs no network connection.

Select a molecule to open its branching recorded synthesis Map. Drag the canvas
to pan, zoom or Fit, and select a reaction for conditions and DOI. Use List for
the original reaction cards. Separate fragments mean connecting steps have not
been curated; missing transformations are never invented. Papers contribute normalized
reaction, chemical, solution (solvent/solute), DOI and author facts only. Draft
structures and reaction conditions still require checking against the source.
PDFs, paper text and copied paper figures are not included.

Edits are saved in this browser when browser storage is available. Browser file
storage is browser-specific and may change if the file is moved or renamed,
the browser/profile changes, data is cleared, or privacy settings block storage.
Use Backup JSON regularly and before moving/replacing the HTML. Use Import
package to transfer that compact JSON backup into the new file or browser.
An HTML update does not itself carry your personal edits to another file path.
There is no cross-device synchronization or automatic weekly data update here.

If a storage error appears, keep the page open. Existing stored data is not
overwritten on a failed save. Export a backup while it remains available; resolve
browser storage/privacy restrictions and reload before relying on persistence.

SHA256SUMS.txt identifies these files. browser-manifest.json records the source Git
commit and bundled library checksum. This is a preview, not a signed Windows
installer or an approved production release.

Molecular diagrams use the current recorded SMILES, drawn offline with bundled
RDKit 2026.9.1. Use a current Chrome or Edge browser with WebAssembly support.
Taxol and doxycycline include verified parent structures. Most paper-numbered
intermediates are still unencoded and are labelled honestly. Edit a molecule's
SMILES to add a checked structure. This does not verify its draft reactions.
On an older saved example library, Add verified example structures fills only
matching targets with missing SMILES after making an exact private browser
backup. Existing structures, notes and other records are retained.
