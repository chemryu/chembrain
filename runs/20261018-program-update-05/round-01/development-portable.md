Exact frozen source: `aaf4d8b13d4604e98458cd6eec59cc8205254bae`. Root committed and pushed it; this helper did not commit or push. No source edits after freeze.

The packager consumes the real portable Vite build and requires one module entry, supported local styles and no additional built asset chunks. It rejects module dependencies, CSS imports/relative asset references, linked preload resources and path escapes. JavaScript and CSS are encoded as UTF-8 base64 inside a fixed inline DOM bootstrap, then decoded into `textContent` for style and a module script. There is no eval or external resource loader, and raw strings containing `</script>`, `</style>` or HTML-comment script sequences never enter HTML parser raw-text context. The output is deterministic for the same build and inputs.

Outputs are `release/Chembrain.html`, `README-Browser.txt`, `browser-manifest.json` and `SHA256SUMS.txt`. The manifest records the full source Git SHA, HTML bytes/SHA-256, input library SHA-256 and bundled JavaScript/style checksums without a timestamp.
