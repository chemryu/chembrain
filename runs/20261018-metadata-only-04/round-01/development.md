## Implementation

- Public paper rows are only internal id, DOI, authors. Strict Python/TypeScript allowlists reject unknown fields at each entity/nested level; no abstract/content/quotation wrapper can pass import/export. Reaction facts, encoded structures, stage solvents/solutes/quantities/conditions, yields and source locators remain with unknown values preserved.
- UI and starter generator follow that contract. Explicit legacy projection drops only recognized old citation fields after exact original browser bytes are backed up locally. Failed backup/unsupported data retains original primary bytes and disables unsafe import/export until recovery. Compact backups contain only current normalized data; private original backup never uploads.
- Both actual source-PDF PNG crops are removed; unencoded structures show placeholders, encoded chemical SVGs remain generated. Example legacy procedure quotations are removed from current files; reference labels derive from DOI/authors instead of full paper metadata. Local importer still verifies supplied optional local quotes, but no longer requires source prose in distributed manifests; source hashes/locators and chemical verification remain.
- GitHub Actions is always metadata-only, even if a caller omits the flag. Direct PDF ingestion is refused there. No resolver, PDF fetch/save, Store/archive, private pending-queue processing or text candidate generation runs in Actions; CLI also supports explicit --metadata-only. Local bounded private PDF processing stays outside Git. Published durable state contains checkpoints/anchors only, not private PDF queues/provider license/link objects; old snapshots with private queue data fail closed rather than repost.
- Paper-work Actions cache is removed. Dependency caches remain. Source/build gates reject document headers (including renamed PDF), document archives, extracted JSON text and public-schema violations; chemical image folder rejects raster/source image embeds. .gitignore excludes paper originals/private extraction/archive output. These are this program's controls, not a GitHub server rule preventing an owner from manually force-uploading through another route.
