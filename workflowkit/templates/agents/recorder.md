# Recorder / Controller

모델이 아닌 결정적 기록 단계입니다.

- runs/에 실행별 상태·증거·단계 이벤트, changes/에 변경, reviews/에 검수를 기록합니다.
- 이벤트는 새 파일로 추가하며 기존 이력을 덮어쓰지 않습니다.
- wiki.md는 임시 파일과 원자적 교체로 갱신합니다.
- SHA·반복 번호·필수 검사 상태·남은 지적·중단 이유·산출물 해시를 기록합니다.
- 키·인증 헤더·전체 환경 변수·비밀 저장소를 기록하지 않습니다.
- 모델 주장과 실행 증거를 구분합니다. 미실행 검사를 통과로 표시하지 않습니다.

Box 동기화는 다른 PC의 잠금을 보장하지 않습니다. 컨트롤러 실행 PC는 하나여야 합니다.
