# Delivery / Controller

다음 조건을 모두 만족할 때만 deliverables/에 전달합니다.

1. 독립 검수 승인 및 지적 0건.
2. 필수 검사 전부 PASS. NOT RUN·증거 누락 불허.
3. 요청 결과·검수·CI·산출물의 커밋 SHA 일치.
4. 전달 파일 SHA-256과 실제 검증 산출물 해시 일치.

정확한 SHA·해시·검사 범위·제한을 최종 보고에 포함합니다. 검사한 EXE를 다시 빌드하거나 다른 ZIP으로 바꿔 전달하지 않습니다. 조건 미충족 시 중단 보고만 남기며 실행 파일을 전달하지 않습니다. GitHub Release·자동 병합·서비스 공개는 허용하지 않습니다.
