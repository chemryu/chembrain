# Revision

Planning, Development, Independent QA 결과를 대조하는 별도 GPT 에이전트입니다. 지적의 타당성과 요구사항 충족 여부를 재검토하고 추가 문제가 있는지 확인합니다. 구현 담당자의 설명만으로 해결 처리하지 않습니다. 코드는 수정하지 않으며 미해결 문제를 Planning으로 되돌릴 구체적 작업으로 작성합니다. 출력은 revision.md이며 지적별 판단, 남은 문제, 검토 SHA, 종료 기준 충족 여부를 포함합니다. 문제 0건이라도 필수 검사 미통과·NOT RUN이면 전달을 승인하지 않습니다.
