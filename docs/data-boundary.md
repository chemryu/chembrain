# Paper information and GitHub boundary

The public library transfers papers `{id, doi, authors}` plus normalized chemical, reaction and solution tables. IDs/foreign keys, molecule names/encoded structures, participants, solvents/solutes and their quantities, reaction conditions/yields, source page/locator and curation status are technical reaction information. Unknown values remain null. Free notes are concise curation facts, not copied article prose. Unknown fields at every record/nested object are rejected, including abstracts/content wrappers.

The browser shows DOI/author references. Legacy browser records can be explicitly projected after exact original bytes are backed up in private browser storage. A backup failure or unsupported field stops replacement; no legacy backup is sent to GitHub or included in compact exports. Local originals remain the user's data.

GitHub Actions has a hard metadata-only guard: no PDF resolution/download, document ingestion, text candidate creation or local download-queue processing, even if a flag is omitted. The workflow has no paper-work cache. Durable Git state contains bounded checkpoint/anchor control fields only, never the PDF queue, license/link provider objects or review text. Dependency caches do not contain paper work. Local PDF processing is allowed only outside the repository and is not an upload operation.

`.gitignore` excludes PDF/private extraction/archive outputs; tracked/build payload gates reject PDF headers, renamed document archives and raw document JSON fields, and strictly validate the public library. Generated structure SVGs are allowed; copied paper crops are removed. These controls govern this program and its automation; they do not configure a GitHub server rule preventing an owner from manually force-uploading files through another route.

Historical audit is separate. Across the fetched remote heads and locally reachable objects at the prior source, no PDF paths/blobs were found, but two historical JSON quotation blobs and two paper-crop image blobs were found. The audit records only object IDs/paths/counts, never copies the text. New deletion commits do not remove those old objects. No shared-history rewrite, branch deletion, repository Public change or remote Actions cache/artifact deletion was performed. Remote deleted refs, GitHub caches/artifacts and server-retained unreachable objects are not fully inspectable through the available native Git access. Before making this existing repository Public, decide how to handle the known old quotations/images; a separate clean publication repository avoids publishing the old history.
